## What it solves

Personal website and blog where I share experience from DevOps, networking and automation.

## Technologies

- **Astro 5** — static site generator with excellent performance and TypeScript support
- **Tailwind CSS v4** — utility-first CSS framework with dark mode support
- **i18n** — full localization in Slovak (default) and English
- **Content Collections** — blog content in Markdown with typed schema
- **GitHub Pages** — automatic deployment via GitHub Actions
- **Umami Analytics** — privacy-friendly analytics without cookies
- **PageSpeed 100/100/100/100** — maximum score in all categories

## Čo to rieši

Osobný web a blog, kde zdieľam skúsenosti z DevOps, sietí a automatizácie.

## Technológie

- **Astro 5** — statický site generator s výborným výkonom a TypeScript podporou
- **Tailwind CSS v4** — utility-first CSS framework s dark mode podporou
- **i18n** — plná lokalizácia v slovenčine (predvolené) a angličtine
- **Content Collections** — blog obsah v Markdowne s typovanou schémou
- **GitHub Pages** — automatický deploy cez GitHub Actions
- **Umami Analytics** — privacy-friendly analytika bez cookies
- **PageSpeed 100/100/100/100** — maximálne skóre vo všetkých kategóriách
